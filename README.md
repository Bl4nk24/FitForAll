# FitForAll
This project is built with Vue 3 and Vite. It uses Supabase for authentication and storage.
## Prerequisites
- Node.js (version 14 or higher)
- npm (version 6 or higher)
## Getting Started
1. **Clone the repository**:
   ```sh
   git clone https://github.com/your-username/FitForAll.git
   cd FitForAll
   ```
2. **Configure environment variables**:
   Create a `.env` file inside `/FitforAll` and set Supabase credentials.
   Supported variable names:
   - `VITE_APP_SUPABASE_URL` or `VITE_SUPABASE_URL`
   - `VITE_APP_SUPABASE_ANON_KEY` or `VITE_SUPABASE_ANON_KEY`
